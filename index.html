eBay Gateway Owner API

Independent, privately operated utility for its account owner. This is an informational site, not a public service or account sign-up portal.

Purpose

eBay Gateway Owner API assists the operator with product research records, workflow queues, Google Sheets processing, and draft preparation and review for cross-border e-commerce. It does not automatically publish eBay listings; final publication requires the operator's explicit approval.

Google permissions

The current Google Apps Script configuration requests Google Sheets access, script management access, and permission to modify Gmail. The main production Gateway processing uses Google Sheets. Separate staging-only Gmail utilities may search relevant messages and manage labels when explicitly run by the operator. Permissions do not imply that all features run continuously.
